# Shopping-analysis
This project helps to analyze customer patterns using python and Mysql.
Here is the sequential, step-by-step summary of the data cleaning workflow from my notebook:

1) Assessed Dataset Structure: Inspected data types, null counts, and summary statistics to identify profiling inconsistencies.
2) Imputed Missing Values: Filled 37 null entries in the Review Rating column using category-specific medians.
3) Standardized Schema Formats: Converted all column names to lowercase and replaced structural spaces with underscores.
4) Renamed Target Attributes: Shortened the column name purchase_amount_(usd) to a cleaner purchase_amount.
5) Removed Redundant Variables: Dropped promo_code_used after verifying its boolean inputs perfectly matched discount_applied.
6) Binned Continuous Age Data: Segmented individual customer ages into four quantile-based categorical groups.
7) Mapped Frequencies to Days: Converted text descriptions (e.g., Weekly, Fortnightly) into a numeric purchase_frequency_days column.
8) Exported the Normalized Dataset: Saved the final pipeline results to a clean my_data_cleaned_file.csv output file without indexes.
